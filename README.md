# Проект: Тестирование приложения для зоологических наблюдений

Учебный проект по Java, демонстрирующий работу с иерархией классов животных и организацию модульного тестирования.

## 📌 Описание проекта
В проекте реализована логика поведения животных:
- Разделение рациона на травоядных и хищников.
- Иерархия семейств (кошачьи, львы, кошки).
- Определение внешних признаков (наличие гривы у львов в зависимости от пола).
- Специальные персонажи: Реализован класс льва Алекса из мультфильма «Мадагаскар» с уникальными характеристиками.

## 🛠 Технологии и версии
- **Java**: 11
- **JUnit**: 4.13.2
- **Mockito**: 4.8.0 (Core)
- **JaCoCo**: 0.8.7 (плагин для оценки покрытия)
- **Maven**: 3.8.1

## 🧪 Особенности реализации
1. **Dependency Injection**: Проведен рефакторинг класса Lion. Теперь зависимость от класса Feline передается через конструктор. Это позволило использовать Mock-объекты и изолировать логику льва в Unit-тестах. Также исправлена грамматическая ошибка в сообщении исключения.
2. **Наследование и полиморфизм**: На примере класса AlexLion реализовано расширение базовой логики льва. Переопределены методы для соответствия уникальным характеристикам персонажа (0 котят, фиксированный пол, список друзей и место проживания).
3. **Мокирование**: С помощью Mockito созданы заглушки для изоляции тестируемых классов Cat, Lion и AlexLion.
4. **Параметризация**: Реализованы параметризованные тесты для проверки корректности определения гривы льва (`LionParamTest`) и количества потомства у кошачьих (`FelineKittensParamTest`).
5. **Обработка исключений**: Написаны тесты, проверяющие корректность выбрасываемых исключений (с проверкой текста сообщений) при передаче невалидных данных в конструктор.
